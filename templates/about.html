College research project

Explainable AI for consumer purchasing patterns.

ElectroPredict is a consumer-electronics storefront designed to make predictive analytics useful, understandable, and grounded in real product data.

Problem and objective

Consumer shopping interactions can reveal useful purchase patterns, but predictions should be understandable rather than opaque.

This project studies consent-based product searches, views, wishlists, carts, purchases, and ratings to support purchase prediction and product discovery.

Technology stack

HTML CSS Vanilla JavaScript Python Flask SQLite SHAP

The interface presents a working catalogue and research-oriented prediction workflow.

Research workflow

1 User interacts with ElectroPredict.
2 Flask stores consent-based activity data.
3 Data is prepared for model evaluation.
4 Prediction and recommendations are explained.

Research principles

Use realistic data collection, evaluate candidate algorithms with appropriate metrics, and disclose when an interface uses a demo value instead of an actual model output.
